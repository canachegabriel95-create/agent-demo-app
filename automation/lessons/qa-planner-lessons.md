# qa-planner lessons

Rules learned from user corrections. The planner reads this file before every run and appends to it
only when the user corrects it or teaches it something new. Newest last.

Format:

```
## YYYY-MM-DD — <short title>
- Lesson: <the rule>
- Why: <what went wrong or what the user said>
- How to apply: <when and how it changes the plan>
```
